# FCM4E1553 EtherCAT 单轴步进驱动固件

本仓库包含基于 N32G455 的 EtherCAT CoE/CiA402 单轴步进电机驱动固件、TwinCAT PLC 示例、ESI XML 和验证脚本。当前实现 PP（1）、PV（3）、CSP（8）和 CSV（9）模式。

## 目录

- `program/`：MCU 固件、EtherCAT 从站协议栈、芯片库及 Keil 工程。
- `examples/`：TwinCAT Structured Text 示例。
- `tests/`：协议、同步、PDI 和脉冲位置验证源码。
- `tools/`：辅助脚本源码。
- `FCM4E1553_CiA402_SingleAxis_Rev03.xml`：TwinCAT 使用的 ESI 文件。

## 编译与使用

1. 使用 Keil MDK-ARM 打开 `program/FCM4E1553 Ethercat/MDK-ARM/Project.uvprojx`，编译并下载固件。
2. 将根目录 XML 安装到 EtherCAT 主站的 ESI 目录，重新扫描从站。
3. TwinCAT 建议使用 2 ms PLC Task、DC-Synchron、SYNC0 x1；当前硬件未连接 SYNC1，应保持关闭。
4. 按 CiA402 顺序写入控制字 `0x0006 -> 0x0007 -> 0x000F`，并确认状态字后再启动运动。

`tests/` 中涉及固件仿真的脚本需先重新编译生成 `MDK-ARM/N32G455/N32G455.axf`，并按测试脚本要求安装 Python 依赖。

## 重要边界

- 当前为开环步进控制，`0x6064` 和 `0x606C` 是内部执行位置与速度，不是编码器测量值。
- 回零、编码器闭环、正负限位、探针输入、力矩控制和 STO 安全功能尚未实现。
- 通信异常或从站退出 OP 后不得自动恢复旧运动，应先清零目标、确认状态并重新完成使能流程。

## 电压、电流及监测映射

依据 STN245M_V1.2 原理图核对：ADC0/PB11 为 A 相电流，ADC1/PB13 为 B 相电流，ADC2/PE12 为电机母线电压；VDDA 标称 3.3 V。母线分压为 100 kΩ / 2 kΩ（51 倍），电流传感器输出经 10 kΩ / 20 kΩ 分压（2/3）。ADC3/PE13 不解释为母线电流或温度。

**不是 ID256EC 的完整替代固件。** 原参考 XML 有 119 个对象，本 XML 从 39 个增加到 67 个：新增 21 个监测/标定对象、补充 7 个 PDO 映射记录。保留本产品身份和 Rev03，不改默认 PDO。厂商私有对象只能参考地址、类型和名称，不能据 XML 推断单位、控制算法或存储协议。

下表均为子索引 `00`；RO 表示只读，所有新增 RO 对象可映射到 TxPDO。标定参数只允许在 PREOP 且电机禁用、内部运动停止后通过 SDO 写入，不允许 RxPDO 修改。

| 地址 | 类型/权限 | 作用与单位 |
|---|---|---|
| `6079` | UDINT / RO | 实际母线电压，mV；未就绪或失效时无有效读数 |
| `2065` | UINT / RO | 同一母线电压，0.1 V/单位；此单位是本固件定义 |
| `2003`、`2004` | DINT / RO | A、B 相有符号电流，mA；默认按 MT9221CT-10BR5 名义参数换算，实物精度需标定 |
| `2064` | INT / RO | 两相电流矢量幅值 `sqrt(Ia²+Ib²)`，mA；不是母线电流、不是相电流 RMS |
| `6078` | INT / RO | 电流幅值 / `6075` × 1000，非负；额定参考电流未设置时无效 |
| `6077` | INT / RO | 原有实际转矩地址；缺少可靠转矩反馈，明确不可用，不以电流冒充转矩 |
| `2002` | DINT / RO | 预留母线电流，mA；本硬件没有相应 ADC 通道，明确不可用 |
| `2001` | UINT / RO | 数据有效性与异常位，见下文 |
| `2005` | UINT / RO | 母线电压 ADC 原始码，0～4095 |
| `2006`、`2007` | UINT / RO | 两相电流 ADC 原始码，每组同相四次采样的平均值 |
| `2008` | UDINT / RO | 最近发布快照的 ADC 序号；不是总线收帧计数 |
| `206D` | UINT / RO | CiA402 状态字的监测镜像，不采用参考驱动器的未知 RunState 编码 |
| `206E`、`206F` | UINT / RO | 板版本 `0102h`、本监测接口版本 `0100h`，不是其他产品的版本 |
| `60F4` | DINT / RO | PP/CSP 下内部目标位置减已执行位置，单位 count；不是编码器跟随误差，PV/CSV 下无效 |
| `2010` | UDINT / RW | ADC 参考电压，mV；默认 3300，范围 2800～3600 |
| `2011` | UDINT / RW | 传感器自身输出灵敏度，µV/A（在 2/3 分压之前）；默认 200000＝200 mV/A，写 0 禁用电流换算，非零范围 10000～1000000 |
| `2012`、`2013` | UDINT / RW | 两相零电流时 ADC 引脚电压，µV；默认名义值 1666667，范围 500000～2800000 |
| `6075` | UDINT / RW | 电流归一化参考幅值，mA；默认 0＝未设，非零范围 100～10000；只改变显示比例，不改变电机驱动电流 |

`2001` 有效位：bit0＝电压，bit1＝两相电流及矢量幅值，bit2＝`6078`，bit3＝转矩，bit4＝母线电流，bit5＝内部 PP/CSP 位置误差。当前 bit3、bit4 始终为 0。异常位：bit8＝采样过期/未就绪，bit9＝DMA 错误，bit10＝ADC 饱和或超出监测量程，bit11＝灵敏度为 0（未配置/禁用），bit12＝额定参考电流未设。**有效位只代表采样与计算条件满足，不代表传感器型号已经实物确认或完成标定；bit11 清零也不代表已标定。**

测量失效时 SDO 返回不可读取错误（`08000020h`）；不支持的转矩和母线电流返回硬件不可用（`06060000h`）。PDO 不能返回 SDO 错误，因此使用无效哨兵：INT=`-32768`、DINT=`-2147483648`、UDINT=`FFFFFFFFh`、UINT 电压=`FFFFh`。**PLC 必须先检查相应有效位，不能将无效值用于控制或当作零值。** ADC 错误/未更新超过 5 ms 后撤销测量有效位；内部位置误差独立于 ADC，但不代表真实轴反馈。

### 标定与接入

1. 保持原 PLC 默认配置即可继续使用 `1600/1A00`，Rx/Tx 均为 12 字节。新增对象可先从 CoE Online 用 SDO 读取。
2. 若需要周期反馈，在安全停机后的 PREOP 中，将 `1C13:01` 从 `1A00h` **替换**为 `1A03h`，`1C13:00` 保持 1；RxPDO 仍为 `1600h`。不要同时分配两个 TxPDO。重新生成、激活配置并检查 PLC 输入链接。
3. 可选 `1A03` 为固定只读映射、42 字节：前 12 字节与原反馈相同，后续字节偏移依次为 `12:2001`、`14:6078`、`16:6079`、`20:2003`、`24:2004`、`28:2002`、`32:6077`、`34:60F4`、`38:2008`。默认不启用它。
4. 根据用户指定，默认采用 **MT9221CT-10BR5** 的软件参数配置。厂家 [MT9221 数据手册 Rev 2.0，第 9 页](https://www.magntek.com.cn/upload/pdf/202412/MT-3-DS-000133%20MT9221%20Fully%20Integrated%20Current%20IC%20Datasheet%20Rev%202.0.pdf) 给出：5 V 供电、双向 ±10 A、200 mV/A、零电流输出为 VCC/2。对应 `2011=200000`，经板上 2/3 分压后 `2012=2013=1666667 µV`（ADC 端），ADC 端有效斜率约 133.333 mV/A。图纸及此前丝印仍为 MT9220，软件配置不证明两种芯片等效，也不表示实物已替换。正式使用前核对实物、供电及零点，并用已知电流验证比例与方向；未知时可将 `2011` 写 0 禁用换算。
5. 换算：`Vbus_mV = ADC2 × Vref_mV × 51 / 4095`；`Iphase_mA = (ADC × Vref_mV × 1000 / 4095 - 零点_µV) × 3 × 1000 / (2 × 灵敏度_µV/A)`。软件监测范围为每相 ±10 A，超出后标无效；这不是新的过流保护阈值。3.3 V、分压阻值和零点均有误差，需要实机验证。
6. 标定参数仅在 RAM 生效，重新上电恢复默认；需要时由主站 PREOP 启动 SDO 重新写入。标定只影响监测，不修改原 PWM、电流环、速度环或过流保护。

默认配置在新鲜 ADC 采样后即可读取 `2003/2004/2064`；要读 `6078`，还需在安全停机的 PREOP 中填写与矢量幅值定义一致的 `6075`，不能将传感器 10 A 量程当作电机额定值，也不要直接混用相电流 RMS 与矢量幅值。`6075=0` 时 `6078` 的 SDO 读取仍返回 `08000020h`，PDO 仍为 `-32768`；这是参考值缺失，不表示电流为零。选择 `1A03` 后，A/B 相电流不依赖 `6075`，可直接周期传输，PLC 需检查 `2001.bit1`；`6078` 则检查 bit2。

传感器为比例式输出，实际 5 V 电源偏差会同时影响零点与灵敏度。当前软件不自动测量该电源：`2010` 应填写实际 VDDA，`2012/2013` 填写各相确认零电流时的 ADC 引脚电压，`2011` 填写实际供电条件下的传感器端灵敏度。若旧 TwinCAT Startup 列表仍写 `2011=0`，将覆盖新默认值，应按实际器件/标定结果修正。没有零点标定、非零已知电流校验之前，仅用于监测调试，不用于过流保护或闭环反馈。

### 验证

2026-10-17 本地完整重编译：0 错误、10 项原有警告；75 项 ARM 仿真测试（遥测 18、运动功能 20、PDI/配置 37）、25 项同步回放测试及 ESI 一致性检查通过。遥测覆盖 MT9221 默认参数、正负电流换算、量程边界、额定值未设、真实 TxPDO 打包、手动校准参数与重置恢复。尚未完成新固件的实板验证。

构建入口仍是 `Project.uvprojx`；未自动下载固件或操作电机。可执行 `tests/verify_drive_esi.py`（XML 经 stdin 输入）、`tests/verify_drive_telemetry.py`、`tests/verify_drive_features.py`、`tests/verify_pdi_faults.py`、`tests/verify_ethercat_sync.js`。ARM 仿真需 `unicorn`、`pyelftools`，并先构建最新 AXF。测试覆盖寄存器与 XML 一致性、换算/失效边界及原有通信/运动保护，不能替代实板标定、TwinCAT 导入验证、持续运行或 EtherCAT CTT 测试。
