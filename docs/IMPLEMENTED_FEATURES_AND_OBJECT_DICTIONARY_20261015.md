# FCM4E1553 驱动器：已实现功能与对象地址说明

整理日期：2026-10-15。适用对象：当前工作区单轴 N32G455 固件及 `FCM4E1553_CiA402_SingleAxis_Rev03.xml`。

本文按**当前源码的执行逻辑**编写，不直接把成品 iD256-EC 手册中的功能当作本机能力。文中的“已实现”表示存在对应的软件执行路径；不代表完成实板验收、长期可靠性验证或 EtherCAT/CiA402 认证。

## 1. 先看这几条

- 已实现的模式：PP（1）、PV（3）、CSP（8）、CSV（9）。上电默认模式为 CSV（9），不等于上电自动使能。
- 本机为开环控制。`0x6064` 是实际输出链推进的励磁相位位置计数；`0x606C` 是由相位推进推算的速度，**不是编码器测量值**。
- 原点、正负硬限位、探针、编码器按用户要求暂不实现。SYNC1 未接线，硬件中断已屏蔽。
- 软件限位 `0x607D`、力矩反馈 `0x6077`、插补周期 `0x60C2` 虽然存在地址，但不等于相关物理功能已经实现，详见第 10 节。
- 默认速度单位仍为 rpm，加减速度单位为 rpm/s；不能把成品驱动器的脉冲/秒参数直接照搬到默认配置。
- 普通禁用、撤电压、非 OP、硬件/PDI 故障等条件可使最终四路 PWM 输出归零。**可能失去保持力**，竖直或重力负载需独立制动或支撑。这不是 STO。
- 本文不执行烧录、使能或运动。测试需有独立停机手段，不得通过强制变量、屏蔽故障或增大容错门限来绕过保护。

## 3. 地址、数据类型和单位怎么读

### 3.1 地址不是同一类

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `0x607A:00` | CoE 对象索引 + 子索引 | 目标位置，通过 SDO 或映射后的 PDO 访问 |
| PDO 字节 2～5 | 周期数据包内的相对偏移 | 默认 RxPDO 中的 607A |
| ESC `0x1100` | ESC 内存中的过程数据缓冲区起点 | 不是 CoE 对象 1100 |
| PLC `%Q*` / `%I*` | TwinCAT 为变量分配的过程映像地址 | 需要正确链接到对应从站 PDO |
| Debug `0x2000xxxx` | MCU RAM 中某变量的内存地址 | 随编译布局变化，不是对象 2000 |

本文对象索引、子索引和控制字均用十六进制；普通速度、位置和计数默认用十进制。单值对象使用子索引 `:00`。记录/数组的 `:00` 通常是有效项数或最大子索引，不是运动参数。

| 类型 | 位数 | TwinCAT 常用类型 | 范围/用途 |
| --- | --- | --- | --- |
| U8 / I8 | 8 | USINT / SINT | 0～255 / -128～127 |
| U16 / I16 | 16 | UINT / INT | 0～65535 / -32768～32767 |
| U32 / I32 | 32 | UDINT / DINT | 无符号计数 / 有符号位置及速度 |
| U64 | 64 | ULINT | 时间戳 |
| BOOL | 1 | BOOL | 标志位 |

`RO`：只读；`RW`：可读写；`RW-PREOP`：仅 EtherCAT PREOP 状态允许写。表中的 RW 不是“任何时刻都能写”，仍受对象回调和状态限制。

PDO 方向以从站为准：Rx 是主站→驱动，Tx 是驱动→主站。标注“可映射”表示对象字典有映射权限，不表示已加入默认 PDO，也不保证可以不修改 ESI 就在 TwinCAT 任意添加。

### 3.2 单位与分辨率

| 2000:00 | 60FF、606C、607F、6081 | 6083、6084、6085 | 607A、6064、60B0 |
| --- | --- | --- | --- |
| 0（上电默认） | rpm | rpm/s | 逻辑位置计数 |
| 1 | 逻辑计数/s | 逻辑计数/s² | 逻辑位置计数 |

每转逻辑计数来自当前 `sxifen`，默认 1000；本版没有新增可通过 CoE 修改每转计数的对象。不要在运行中修改分辨率。

换算公式：`rpm = 计数/s × 60 / 每转计数`。例如 1000 计数/转时，计数制速度 1000 表示约 60 rpm。

改变 `2000:00` 必须同时满足 PREOP、未使能、内部相位执行链已停止。改变后清零 60FF，并重置速度/斜坡参数，不保留原始数值直接重新解释。默认 1000 计数/转时，从 0 改为 1 后：

| 地址 | 改单位后的值 | 对应物理量 |
| --- | --- | --- |
| 607F:00 | 16666 | 约 1000 rpm 上限，整数换算向下取整 |
| 6081:00 | 1666 | 约 100 rpm 轮廓速度，向下取整 |
| 6083:00 / 6084:00 / 6085:00 | 5000 | 300 rpm/s |
| 60FF:00 | 0 | 停止速度目标 |

底层速度以 1/16 rpm 为步进量，转换向零截断；小于一步会变为零。PP 规划速度及斜坡参数仍按整数 rpm / rpm/s 处理。重上电单位回到 0；其他 CoE 设置也不要假定已持久化。

### 4.1 参数写入限制

1. 默认 rpm 单位下，607F/6081 接受 1～1000；6083/6084/6085 接受 1～10000。0 和超范围值拒绝。
2. 计数制下，最小有效值为 `ceil(每转计数/60)`；速度最大值为 `floor(1000×每转计数/60)`，斜坡最大值为 `floor(10000×每转计数/60)`。
3. 2000、605A～605E、607F、6081、6083、6084、6085 使用参数校验回调；子索引、数据长度、范围错误会被拒绝。此回调不接受 Complete Access，按单对象 `:00` 写入。
4. 存在待完成停止转换或处于 Quick Stop Active 时，上述回调拒绝改参。建议停机后配置参数。
5. 60FF 是有符号 32 位目标，实际运行速度仍受 607F 和 1000 rpm 固件硬上限限制；硬上限不表示电机在该速度下必然有足够转矩。
6. PV/CSV 不用 6081 限制速度，应配置 607F。CSP 的上限过低会使内部位置跟不上主站轨迹。
7. 不支持的模式不能按“写得进去就能运行”理解；应检查 6061、6041 及实际输出状态。

## 5. 停止对象：各选项实际做什么

### 5.1 605A:00 快速停止

在已使能状态发出 Quick Stop（典型控制字 `0x0002`）时生效。

| 值 | 动作 | 完成后的状态 |
| --- | --- | --- |
| 0 | 立即禁止驱动输出 | Switch On Disabled |
| 1 | 按 6084 减速 | Switch On Disabled |
| 2（默认） | 按 6085 减速 | Switch On Disabled |
| 5 | 按 6084 减速 | 保持 Quick Stop Active |
| 6 | 按 6085 减速 | 保持 Quick Stop Active |

3、4、7、8 等值不支持；本机不虚报电流限制/电压限制制动。5/6 停止后不能仅发送旧 `0x000F` 自动继续，需先 `0x0000`，再执行新的 `0x0006→0x0007→0x000F` 启用过程，并重新准备有效运动目标。

### 5.2 605B / 605C / 605D / 605E

| 对象 | 支持值 | 本机动作 |
| --- | --- | --- |
| 605B Shutdown | 0 / 1 | 运行中收到 0006：0 立即退出运行；1 用 6084 减速后到 Ready to Switch On |
| 605C Disable operation | 0 / 1 | 运行中收到 0007：0 立即退出运行；1 用 6084 减速后到 Switched On |
| 605D Halt | 1 / 2 | PP/PV 的 bit8=1：1 用 6084，2 用 6085；保留继续运行所需目标 |
| 605E Fault reaction | 0 / 1 / 2 | 对象保留立即退出/正常斜坡/快速斜坡选项；当前硬件/PDI 故障先关输出，不能据此承诺故障时仍执行受控机械减速 |

内部停止完成需检查实际相位输出链和斜坡状态，不靠把 606C 强行写成 0。故障会取消旧普通停止请求，避免后续中断用旧状态覆盖故障状态。

`6040 bit1=0`、非 OP、PDI 锁存、硬件故障等关断条件优先于普通减速。软件停止完成不等于机械轴已经停止，尤其在惯性负载或失去保持力时。

## 6. 控制字 6040 与状态字 6041

### 6.1 常用控制位

| 6040 位 | 掩码 | 本机用途 |
| --- | --- | --- |
| bit0 | 0x0001 | Switch on，配合状态机命令使用 |
| bit1 | 0x0002 | Enable voltage；清零进入禁止输出路径 |
| bit2 | 0x0004 | Quick Stop 控制；常规使能时为 1，清零可发出快速停止 |
| bit3 | 0x0008 | Enable operation |
| bit4 | 0x0010 | PP 新目标触发，要求 0→1 上升沿 |
| bit5 | 0x0020 | PP 立即执行；本机单目标握手要求置 1 |
| bit6 | 0x0040 | PP：0 绝对目标，1 相对目标 |
| bit7 | 0x0080 | Fault reset，要求先观察到 0 再出现新上升沿 |
| bit8 | 0x0100 | PP/PV Halt；不作为 CSP 暂停指令 |
| bit9～bit15 | — | 本文不声明其他控制功能，正常命令不要随意置位 |

PP 相对目标是接受命令时的内部当前位置加 607A，不是无限累加目标。保持 bit4=1 不会反复启动同一个目标；再次启动需重新拉低再拉高。

### 6.2 常用命令

| 控制字（十六进制） | 用途 |
| --- | --- |
| 0000 | 禁止输出/撤电压；不是受控机械减速命令 |
| 0006 | Shutdown / 请求 Ready |
| 0007 | Switch on；运行中也表示 Disable operation |
| 000F | Enable operation |
| 0002 | Quick Stop，使用 605A 配置 |
| 0080 | 故障复位高电平阶段；必须在故障消除及新低→高边沿条件下使用 |
| 002F → 003F | PP 绝对位置单目标握手 |
| 006F → 007F | PP 相对位置单目标握手 |

Halt 应在当前合法控制字上设置 bit8，而不是把整字直接改成 `0100`。例如 PV 的 `000F→010F`。清除 bit8 表示允许继续，不能把它当成无副作用的“清报警”。

### 6.3 用状态掩码判断

计算 `state = 6041 AND 0x006F`：

| 掩码结果 | 状态 | 含义 |
| --- | --- | --- |
| 0000 | Not Ready to Switch On | 尚未准备好 |
| 0040 | Switch On Disabled | 禁用，需重新进行启用过程 |
| 0021 | Ready to Switch On | 准备好，等待 Switch on |
| 0023 | Switched On | 已上电状态，尚未运行使能 |
| 0027 | Operation Enabled | 运行使能 |
| 0007 | Quick Stop Active | 正在快速停止或按 5/6 保持在此状态 |
| 000F | Fault Reaction Active | 故障处理过程 |
| 0008 | Fault | 故障状态 |

不要直接判断 `6041==0x0027`：bit9、bit10、bit12 等附加位可能同时存在。

| 状态位 | 掩码 | 使用说明 |
| --- | --- | --- |
| bit3 | 0x0008 | 故障状态指示，结合状态掩码及 603F 看 |
| bit4 | 0x0010 | 软件电压使能状态，不是独立测得母线已经安全 |
| bit5 | 0x0020 | Quick Stop 状态相关位，快速停止时通常为 0；不要单独作为全部状态判据 |
| bit6 | 0x0040 | Switch On Disabled |
| bit7 | 0x0080 | 保留警告语义；本机未实现完整分级预警体系 |
| bit9 | 0x0200 | Remote，控制字处理状态；不是以太网链路健康证明 |
| bit10 | 0x0400 | 模式相关的内部目标完成；PP 到位、PV 到速或 Halt/停止完成等 |
| bit11 | 0x0800 | 内部限制生效，如速度限幅、位置数值边界；不等于 607D 软件限位已实现 |
| bit12 | 0x1000 | PP：新目标确认；PV：内部零速；CSP/CSV：内部跟随命令标志 |
| bit13 | 0x2000 | 不声明真实编码器跟随误差或回零错误检测 |

bit10/bit12 只能反映内部执行链，不能据此检测丢步。PP bit12 需要结合新目标触发与 bit4 清零握手使用，不能跨模式套用同一含义。

### 7.2 当前故障对应关系

| 故障来源 | 206C（十进制） | 603F（十六进制） | 1001 分类 | 实现边界 |
| --- | --- | --- | --- | --- |
| VFO 驱动保护输入触发 | 10 | 7120 | 21 | 已有检测路径；不能仅凭 VFO 断言是过流、缺相或欠压中的某一种 |
| 缺相/电枢回路中断报告入口 | 11 | 3321 | 21 | 有上报映射；不能据此声称已实现独立缺相检测 |
| 母线欠压报告入口 | 13 | 3220 | 05 | 有上报映射；独立电压采样、门限和实板保护尚未验收 |
| 母线过压报告入口 | 14 | 3210 | 05 | 同上 |
| MCU↔ESC PDI 故障锁存 | 不另分配上述厂商号 | 7500 | 置位 11 | 看 gEscPdiDiag；不等于主站 WcState 错误计数 |

表中 1001 分类值也是十六进制。1001 的 bit0 为一般错误，bit2 为电压类，bit4 为通信类，bit5 为设备配置文件相关分类；这些位不是独立的电流/电压测量结果。

TwinCAT 日志里的 AL 状态码 `0x001A` 表示同步错误，属于 EtherCAT 状态机层；它不是 603F 的 0x7500，也不是 206C 的十进制 10。

故障复位前先消除真实原因。普通故障要求新的 bit7 上升沿；PDI 故障还要求现有固件的新 PDO、复位低电平先行、未使能/停止及连续健康通信等条件。不得循环写复位来掩盖仍存在的故障。

映射描述值格式：`(对象索引 << 16) | (子索引 << 8) | 位长度`。例如 0x607A0020 表示 607A:00、32 位，不是直接可写的目标位置。

固件有其他映射模板和校验逻辑，但当前 ESI 默认 PDO 声明为固定布局，不是成品驱动器多组任意动态映射的等价实现。建议保持默认 12/12 字节接口。更改映射必须同时核对固件容量、ESI、PLC 链接及状态切换，不在运行中尝试。

同一目标只能有一个明确的写入源。PLC 已经周期发送 PDO 时，在 CoE 或 Box 界面手动写控制字/目标，可能马上被下一周期 PDO 覆盖。不要同时让 PLC、手动强制和其他控制程序竞争写入。

### 9.3 1C32 / 1C33 同步参数

`0x1C32` 是 SM 输出侧，`0x1C33` 是 SM 输入侧；两者使用下列子索引。表中子索引均为十六进制，例如 `:0B` 对应十进制 11。

| 子索引 | 类型/权限 | 名称 | 实际用途/默认 |
| --- | --- | --- | --- |
| :00 | U8 / RO | 最大子索引 | 0x20，不表示中间每个子项都可访问 |
| :01 | U16 / RW-PREOP | Synchronization Type | 固件初始化为 FreeRun=0；主站/DC 配置可改写，实际运行读回确认 |
| :02 | U32 / RO | Cycle Time | ns，初始化 0；DC 配置后更新周期，例如 2 ms 为 2000000 |
| :04 | U16 / RO | 支持同步类型位图 | 当前源码初始化含模板能力位，见下方警告 |
| :05 | U32 / RO | Minimum Cycle Time | 500000 ns，即 0.5 ms；是配置声明，不是已实测最短可靠周期 |
| :06 | U32 / RO | Calc and Copy Time | ns，初始化 0，可由协议栈测量路径更新 |
| :08 | U16 / RW | Get Cycle Time | 测量请求控制，初始化 0；不是运动速度设置 |
| :09 | U32 / RO | Delay Time | ns，当前配置初始化 0；不能由 0 推断物理处理无延迟 |
| :0A | U32 / RW | Sync0 Cycle Time | ns，DC 启动检查会由 ESC 周期寄存器同步；不要当作单独改变物理 SYNC0 的入口 |
| :0B | U16 / RO | SM-Event Missed | 同步管理器事件缺失诊断，初始化 0，可能随状态切换复位 |
| :0C | U16 / RO | Cycle Time Too Small | 固件的周期超限计数，初始化 0 |
| :0D | U16 / RO | Shift Time Too Short | 记录字段保留；当前源码未发现递增路径，不能据零值排除相位问题 |
| :20 | BOOL / RO | Sync Error | 同步错误汇总，初始化 0 |

`:03`、`:07`、`:0E～:1F` 在当前描述中没有可用实现，不按连续寄存器读写。

当前已知声明差异：

- ESI 的 :01 默认为输出侧 1、输入侧 0x22；固件启动初始化两侧均为 0，进入具体运行状态后由配置更新。不要把 ESI 离线默认值等同于运行状态。
- ESI 的 :04 默认 0x8007；当前 `COE_ObjInit()` 初始化计算得到 0x401F，含 SYNC1/子周期等模板能力位。**本板 SYNC1 未连接且中断已屏蔽，不能按该位图启用 SYNC1。** 这是待统一的接口声明，不是新增能力。
- 当前使用 DC-Synchron、SYNC0，已有 PLC 示例周期为 2 ms（500 Hz）。SYNC0 有 500 Hz 波形，只证明该引脚有周期信号，不能证明每一帧 PDO 都按时完成。
- 60C2 默认名义 1 ms 与实际 DC 2 ms 可以不同，因为当前执行周期不是由 60C2 设置。周期应在主站任务/DC 配置中一致设置并验证。

| gEscIrqDiag.recoveryRequestCount | 受限软件 IRQ 恢复请求次数 | 应与 IRQ 电平、处理耗时及 PDO 进度一起看 |

PDI `firstError/lastError` 编号：1 参数错误；2 空闲等待超时；3 读超时；4 接收长度不足；5 写超时；6 SyncManager 确认失败。

DWT 时间换算：`时间秒 = 周期差 / SystemCoreClock`。144 MHz 时，144000 周期约 1 ms；633600 周期约 4.4 ms。**144 MHz 是 MCU 时钟，不是 EtherCAT 通信频率。** 32 位计数会回绕，调试暂停、重新初始化和无效标志都会影响解读。

当前外部中断安排为 ESC IRQ（PB0）优先级 0、SYNC0（PB1）优先级 1，电机 TIM8 优先级 2；SYNC1（PB2）屏蔽。数值越小优先级越高，但高优先级不等于不受全局关中断、临界区或异常影响。

## 13. 最小使用流程与常见问题

本节是接口说明，不是自动执行脚本。先确认安全、参数单位、模式、目标方向和停机手段；不要带危险负载试运行。

### 13.1 公共准备

1. 确认只由一个控制源写 PDO；正确链接 WcState 与本从站状态。
2. 停止且未使能时设置模式和参数；如需切换 2000，先进入 PREOP 并满足其附加条件。
3. 速度模式先准备 60FF=0；CSP 先让 `607A+60B0` 与当前 6064 一致，避免一使能就跳到旧目标，计算时检查有符号溢出。
4. 确认 EtherCAT OP、数据有效且无故障；再依次发 0006、0007、000F，并分别等待 6041 掩码为 0021、0023、0027，不能只用固定延时盲写。
5. 任何一步超时或数据失效都停止继续启动，保留诊断，不自动反复重试使能。

### 13.2 PP：给一次位置，应该执行一次后保持

模式 6060=1，检查 6061=1。配置 6081/6083/6084，准备小距离安全目标。例如默认 1000 计数/转时，相对 100 计数是逻辑 0.1 转，不保证机械无丢步。

设置 607A 后：绝对目标使用 `002F→003F`；相对目标使用 `006F→007F`。等待 bit12 确认后，将 bit4 拉低以准备下一次握手，再根据 bit10 和内部位置判断此次目标是否完成。不要每个 PLC 周期制造新的 bit4 上升沿。

如果只给一个有限目标却一直转，优先核对实际 6061 是否为 1、60FF 是否仍非零、PDO 是否覆盖手动值、控制字是否重复触发，以及 6064 是否与实际机械动作一致；不能仅凭界面中写过“PP”判断已进入 PP。

### 13.3 PV / CSV：目标速度持续有效

PV 设置 6060=3，CSV 设置 6060=9；确认 6061 后给 60FF。非零速度目标保持有效时持续旋转是这两种模式的预期行为，不是有限位置运动。

需要停止时使用设计好的零速目标/停止流程；需要 Halt 的 PV 可设 bit8。CSV 不套用 PP/PV 的 Halt 逻辑。停机后是否撤使能取决于负载保持要求及独立安全措施。

### 13.4 CSP：主站必须连续规划位置

设置 6060=8，确认 6061=8。主站每周期更新 607A；模式 8 下不是“给一次目标就按固定速度无限转”。注意 60B0、6081、607F 与轨迹速度的一致性。

正常暂停应由主站规划减速至保持位置，或用已设计的 Quick Stop 流程；不要认为 bit8 会暂停 CSP。恢复通信后先重新确认目标连续性及启动条件，不继续发送失效前的旧运动请求。

### 13.5 “停了”优先看什么

按顺序保存：主站 WcState/帧诊断 → AL 状态及状态码 → 6040/6041/6061 → 603F/1001/206C → MCU 首次错误/首次禁用快照。

WcState 异常、AL 同步错误、PDI 错误和主站主动清控制字是不同层的问题。当前 Realtek demo 网卡相关时序问题，不能仅凭 MCU PDI 计数为零就宣布已排除，也不能仅凭一条较长 PDO 处理间隔就断定线缆丢帧。
