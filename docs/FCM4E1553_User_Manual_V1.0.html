1. 产品概述


1.1 产品简介


FCM4E1553是一款高性能EtherCAT步进电机驱动器，采用N32G455 MCU，支持CiA402运动控制协议。驱动器集成了EtherCAT通信接口，可实现高精度位置控制和速度控制。


主要特点：

  • 支持EtherCAT实时工业以太网通信
  • 符合CiA402设备配置标准
  • 支持PP、PV、CSP、CSV四种运动模式
  • 开环步进控制，逻辑分辨率可配置
  • 集成硬件保护功能
  • 紧凑型设计，尺寸134×77×34mm

1.2 应用场景


  • 自动化生产线
  • 机械手臂
  • 包装机械
  • 印刷设备
  • 实验室设备
  • 其他需要精确位置控制的场合

⚠️ **安全提示**

> **警告**：使用前请仔细阅读本说明书。不当使用可能导致设备损坏或人身伤害。
- 本产品不具备功能安全认证（如STO），不可用于人身安全相关的应用
- 竖直或重力负载必须配备独立的机械制动或支撑装置
- 调试时必须确保周围无人员，并具备独立的急停装置

4. 安装与接线


4.1 安装前检查


  1. ✓ 检查驱动器外观无损坏
  2. ✓ 确认供电电压在规格范围内（24~48VDC）
  3. ✓ 准备合适规格的电机（两相步进电机）
  4. ✓ 准备EtherCAT网线（屏蔽双绞线）

4.2 安装步骤


方式一：DIN导轨安装


  1. 将驱动器挂钩卡入35mm标准DIN导轨
  2. 向下按压至听到"咔"声
  3. 确认安装牢固

方式二：螺钉固定


  1. 使用M4螺钉（4个）
  2. 安装孔间距见第7章尺寸图
  3. 推荐力矩：1.2 N·m

4.3 接线步骤


⚠️ **所有接线必须在断电状态下进行**

步骤1：电源接线


电源+ → CN1 Pin2 (V+)
电源- → CN1 Pin1 (GND)

步骤2：电机接线


电机A+ → CN2 Pin4
电机A- → CN2 Pin2
电机B+ → CN2 Pin3
电机B- → CN2 Pin1

步骤3：EtherCAT接线


主站/上一级 → CN5 (IN)
下一级 → CN6 (OUT)

步骤4：I/O接线（可选）

  • 根据实际需求连接数字输入/输出
  • 参考第6章接线示例

4.4 接线注意事项


  1. ⚠️ 电源线建议使用≥1.5mm²导线
  2. ⚠️ 电机线尽量远离信号线，避免干扰
  3. ⚠️ EtherCAT网线建议使用屏蔽双绞线
  4. ⚠️ 确保所有端子接线牢固
  5. ⚠️ 预留足够的线缆长度，便于维护

9. 运动控制模式


9.1 支持的模式


FCM4E1553支持以下4种CiA402标准运动模式：


模式代码名称说明
PP1Profile Position轮廓位置模式
PV3Profile Velocity轮廓速度模式
CSP8Cyclic Sync Position周期同步位置模式
CSV9Cyclic Sync Velocity周期同步速度模式

❌ 不支持的模式：

  • HM (6) - 回零模式（硬件未实现）
  • PT (4) / CST (10) - 力矩模式（无力矩反馈）

9.2 PP - 轮廓位置模式


适用场景：点到点定位


控制流程：


  1. 设置模式：

`

0x6060 = 1 (设置PP模式)

确认0x6061 = 1

`


  1. 配置参数：

`

0x6081 = 100 (轮廓速度, rpm)

0x6083 = 300 (加速度, rpm/s)

0x6084 = 300 (减速度, rpm/s)

`


  1. 启动运动（绝对位置）：

`

0x607A = 5000 (目标位置, 计数)

0x6040 = 0x002F

0x6040 = 0x003F (bit4: 0→1触发)

`


  1. 等待完成：

`

监控0x6041 bit10 = 1 (到位)

`


握手协议：

  • bit4 (new setpoint): 0→1 触发新目标
  • bit12 (setpoint ack): 驱动器确认
  • 下一个目标前必须先清bit4再拉高

绝对/相对位置：

  • bit6=0: 绝对位置（0x607A为目标坐标）
  • bit6=1: 相对位置（0x607A为相对当前位置的增量）

9.3 PV - 轮廓速度模式


适用场景：恒速运行


控制流程：


  1. 设置模式：

`

0x6060 = 3

确认0x6061 = 3

`


  1. 配置参数：

`

0x607F = 1000 (最大速度限制, rpm)

0x6083 = 300 (加速度)

0x6084 = 300 (减速度)

`


  1. 启动运动：

`

0x60FF = 100 (目标速度, rpm, 正值=正转, 负值=反转)

0x6040 = 0x000F (使能)

`


  1. 停止运动：

`

0x60FF = 0 (设置速度为0)

`


注意事项：

  • 非零速度目标会持续旋转
  • 停止需设置目标速度为0或禁用驱动器
  • Halt功能：0x6040 bit8=1可减速暂停

9.4 CSP - 周期同步位置模式


适用场景：主站实时轨迹控制


控制流程：


  1. 设置模式：

`

0x6060 = 8

确认0x6061 = 8

确认0x6041 bit12 = 1 (跟随命令标志)

`


  1. 配置参数：

`

0x6081 = 100 (跟随速度上限, rpm)

0x607F = 1000 (最大速度限制, rpm)

`


  1. 周期更新位置：

`

每个周期(如2ms)更新0x607A

主站负责轨迹规划

`


重要特性：

  • ⏱️ 20ms相位跟随：驱动器内部使用约20ms滤波平滑PDO位置
  • 📊 滞后时间：会引入约20ms的相位滞后
  • 🔄 持续更新：必须每周期更新目标，不能给一次目标就停止更新
  • ⚠️ 失联保护：超过10个周期未更新会触发保护停机

位置偏移：


实际目标 = 0x607A + 0x60B0 (位置偏移)

到位判断：

  • bit10 (target reached): 目标完成标志
  • 条件：位置匹配 AND 速度为0
  • 建议等待连续100ms确认静止

9.5 CSV - 周期同步速度模式


适用场景：主站实时速度控制


控制流程：


  1. 设置模式：

`

0x6060 = 9 (默认上电模式)

确认0x6061 = 9

确认0x6041 bit12 = 1

`


  1. 配置参数：

`

0x607F = 1000 (最大速度限制)

`


  1. 周期更新速度：

`

每个周期更新0x60FF

速度=0也是有效命令

`


注意事项：

  • 与PV类似，但主站周期控制
  • 目标速度为0也必须持续发送
  • 受0x607F限制

11. 常见问题


11.1 启动和使能


Q1: 如何启动电机运动？


A: 完整启动流程：


  1. 确认EtherCAT已进入OP状态
  2. 确认无故障（0x6041 bit3=0）
  3. 确认数据有效（主站WcState正常）
  4. 发送控制字序列：

`

0x6040 = 0x0006 (Shutdown)

等待0x6041 = 0x0021 (Ready to Switch On)


0x6040 = 0x0007 (Switch On)

等待0x6041 = 0x0023 (Switched On)


0x6040 = 0x000F (Enable Operation)

等待0x6041 = 0x0027 (Operation Enabled)

`

  1. 设置目标位置/速度
  2. 开始运动

Q2: 使能后电机不转？


A: 检查项：

  • ✓ 确认0x6061等于请求的模式
  • ✓ PP模式：检查是否发送了bit4上升沿
  • ✓ 检查目标值是否为0
  • ✓ 检查0x6041 bit12状态
  • ✓ 检查最大速度限制0x607F
  • ✓ 用万用表测量电机绕组是否通电

Q3: EtherCAT状态无法进入OP？


A: 可能原因：

  • 网线未连接或损坏
  • ESI文件与固件不匹配
  • 主站配置错误
  • 检查LED指示灯状态

11.2 运动控制


Q4: PP模式给一次目标却一直转？


A: 可能原因：

  • 实际模式不是PP（检查0x6061）
  • 0x60FF目标速度不为0
  • PLC每周期重复触发bit4
  • 检查PDO映射是否被覆盖

Q5: CSP模式运行一段时间自动停转？


A: 这是本文档重点解决的问题，可能原因：


  1. PDO失联保护触发：超过10个周期未更新
  • 检查主站PLC任务是否停止
  • 检查WcState是否异常

  1. 通信异常：
  • 查看gEscPdiDiag.faultLatched
  • 查看主站错误计数

  1. 硬件故障：
  • 查看0x603F错误码
  • 查看0x206C厂商错误码

解决方法：

  • 参考已提供的诊断工具
  • 查看docs/CSP_STOPPING_ISSUE_SOLUTION_PLAN.md
  • 保存停机快照进行分析

Q6: 位置到位判断不准确？


A: 注意：

  • 0x6064是内部计数，不是机械位置
  • 需要外部测量验证机械精度
  • 开环控制可能存在丢步
  • 到位判断需等待静止确认

11.3 参数配置


Q7: 如何修改速度单位？


A: 修改0x2000，步骤：

  1. 进入PREOP状态
  2. 确保已禁用驱动器
  3. 写入0x2000 = 0 (rpm) 或 1 (计数/s)
  4. 重新配置速度参数
  5. 参数不保存到掉电后

Q8: 如何修改逻辑分辨率（每转计数）？


A: 当前版本不支持通过CoE修改，固定为1000计数/转。修改需要：

  • 修改固件中的sxifen变量
  • 重新编译烧录

Q9: 参数掉电后丢失？


A: 当前版本不支持参数持久化，每次上电后恢复默认值。


11.4 故障处理


Q10: 故障如何复位？


A: 故障复位流程：


  1. 检查故障原因（0x603F, 0x206C）
  2. 消除故障根本原因
  3. 发送Fault Reset：

`

0x6040 = 0x0000 (先清零)

等待

0x6040 = 0x0080 (上升沿)

`

  1. 等待0x6041退出Fault状态
  2. 重新启用驱动器

⚠️ **不能循环自动复位掩盖故障**

Q11: PDI故障如何恢复？


A: 特殊流程（详见技术文档）：

  1. 保持0x6040 = 0x0000
  2. 等待通信稳定（pdoSincePdiError ≥ 32）
  3. 确认电机静止
  4. 发送Fault Reset
  5. 查看gEscPdiDiag.faultLatched清零

Q12: 常见错误码含义？


错误码说明解决方法
0x7120VFO保护检查过流/电机/接线
0x3220欠压检查电源电压
0x3210过压检查电源/再生
0x7500PDI故障检查通信质量

11.5 调试技巧


Q13: 如何查看内部诊断变量？


A: 使用Keil调试器Watch窗口：


gEscPdiDiag          - PDI诊断
gEcatCommDiag        - 通信诊断
gEcatSyncDiag        - 同步诊断
gEcatPulseDiag       - 相位诊断
gMotorIsrMaxCycles   - 中断时间

Q14: 如何测量机械精度？


A:

  • 在轴端做标记
  • 使用角度测量仪/编码器
  • 运行PP模式整圈运动
  • 对比标记位置偏差
  • 不能仅靠0x6064判断

Q15: 如何优化停止时间？


A: 调整减速度参数：

  • 0x6084（正常减速）
  • 0x6085（快速停止减速）
  • 范围：1~10000 rpm/s
  • 值越大停止越快
