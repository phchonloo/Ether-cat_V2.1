# 常用驱动功能补齐与边界

日期：2026-10-15。参考：用户提供的 ID256EC.xml，以及 iD256-EC 说明书 V1.2 第 20～24 页。

结论：本版补齐适用于现有开环硬件的常用控制行为，**不是 iD256-EC 的 1:1 替代固件**。ESI 只描述接口，不能证明电流、反馈精度、同步性能、额定能力或保护效果等同。

用户已明确：原点、正负限位、探针、编码器没有接线，本次不实现。没有分配这些功能的引脚，没有启用 HM，没有启用未连接的 SYNC1。

## 1. 功能对照

| 项目 | 本次交付 | 边界 |
| --- | --- | --- |
| PP=1 | 保留绝对/相对单目标、02F→03F 握手、到位保持；补齐 Halt 的停止完成位；目标与控制字短临界区快照 | 支持立即执行单目标；不增加缓冲队列、轨迹拼接 |
| PV=3 | 保留正反向速度和加减速；补齐 bit8 Halt、bit12 零速、bit10 到速/停止完成 | 单位见 0x2000；低速受整数相位步进量化限制 |
| CSP=8 | 保留周期目标与相位计数，新增 60B0 位置偏移及加法溢出保护 | 原有约 20 ms 平滑仍在；不是无滞后的闭环伺服 |
| CSV=9 | 保留并回归；支持可选速度单位及最大速度限制 | 参考常用功能页未重点描述，作为已有能力保留 |
| 605A 快速停止 | 支持 0、1、2、5、6；使用实际 16 kHz 相位输出减速，不再伪造零速反馈 | 5/6 停留 Quick Stop Active，不接受旧 0F 自动恢复；需 00 后重新 06/07/0F |
| 605B/605C | 0 立即退出；1 用 6084 减速后完成状态转换 | 不提供电流限制或电压限制制动策略 |
| 605D Halt | 新增，1 用 6084，2 用 6085；适用于 PP/PV | CSP 不把 bit8 当暂停；主站须规划保持目标或使用 Quick Stop |
| 605E 故障 | 保留硬件/PDI 故障立即关断优先级，修复旧斜坡残留导致的完成条件卡住 | 参数不能覆盖硬件故障关断；不等价于功能安全 |
| 状态机 | OP 本身不再自动推进到 Ready；正常 06/07/0F；快速停止期间 6041 立即显示当前状态；复位要求 bit7 新上升沿 | 不照抄成品厂家专用状态位组合 |
| 607F | 新增最大速度上限，覆盖现有 PP/PV/CSP/CSV 命令限幅 | 同时受固件 1000 rpm 硬上限限制；不是额定速度承诺 |
| 6081/6083/6084/6085 | SDO 写入范围、长度、子索引校验；停止过渡中禁止修改参数 | 保持 SDO 配置；未复制成品的多组动态 PDO 布局 |
| 回零、硬限位、探针、编码器 | 按用户要求不做、不声明支持 | 6502 默认 0x185；速度专用映射不再错误声明 HM |
| 20F1 电流设置 | **未实现** | 现有电流算法在 N32G455.lib，未见可验证的安培标定/限幅写入接口；不能凭名字给 Am/WorkValue 赋值 |

6064 是算法实际推进的励磁相位计数，不是轴端编码器位置。606C、到位、零速及本版停止完成也以该内部执行链为依据，不能检测丢步或证明机械轴已停稳。

607D 等原有保留对象不因本次补齐而变成已验收功能。本次不新增软件/硬件限位执行器，不实现 60FD 数字输入或闭环跟随误差检测。参数持久化、断电位置恢复、力矩模式同样不在交付声明内。

## 2. 单位兼容：默认不改变旧 PLC

新增本机厂商对象 `2000:00`，UINT16，SDO，**仅 PREOP、停止且未使能时允许改变**：

| 值 | 60FF / 606C / 607F / 6081 | 6083 / 6084 / 6085 |
| --- | --- | --- |
| 0（上电默认） | rpm，兼容现有 GVL_CSP_NEW | rpm/s |
| 1 | 逻辑计数/s | 逻辑计数/s² |

607A、6064、60B0 始终是逻辑位置计数；每转计数来自当前 `sxifen`。更改单位不会更改位置分辨率。

改变 2000 时会清零 60FF，并重置速度上限及加减速为保守的物理默认值；**不是保留原数值换个标签**。默认 1000 计数/圈时，选择 1 后：6081=1666、607F=16666、6083/6084/6085=5000。重上电仍回到旧单位 0，本版不保存该设置。

换算：`rpm = 计数/s × 60 / 每转计数`。1000 计数/圈时，60FF=1000 约为 60 rpm。

精度边界：底层速度步进量为 1/16 rpm；速度换算向零截断，不足一步会量化为零。PP 速度规划和加减速参数仍是整数 rpm / rpm/s，向下取整；参数最小值必须至少可表达 1 rpm / rpm/s，否则 SDO 拒绝。需要更高低速/加速度分辨率时，须另行改造规划器并实测，不能宣称与闭环成品完全一致。

## 3. 控制与恢复顺序

先确认电机/功率级安全，确保任何运动不会造成人身或设备损害。本文不是设备级安全方案，不自动烧录、使能或启动电机。

- 通用启用：模式及参数准备完成后，写 6040=0006，等待 `(6041 & 006F)=0021`；写 0007 等待 0023；写 000F 等待 0027。
- PP：6060=1，设置 6081/6083/6084 和 607A。6040=002F 后再 003F；bit4 上升沿接受目标，6041 bit12 确认。相对目标用 006F→007F。单次有限目标不会自动重复。
- PP/PV Halt：6040 bit8=1，按 605D 指定斜坡降至零；在停止完成前 bit10 不应为 1。清除 bit8 是明确的继续运行命令：PP 恢复保留的目标，PV 恢复目标速度。
- Quick Stop：6040=0002；默认 605A=2 按 6085 减速，完成后退出至 Switch On Disabled。605A=5/6 保持 Quick Stop Active；必须先 0000，再重新 0006/0007/000F，不自动继续旧请求。
- 6040=0000、OP 丢失、PDI 锁存及硬件保护优先于普通减速；不得为持续转动而屏蔽这些路径。
- 故障复位：先处理实际故障，再 bit7 从 0→1。一直保持 0080 不会反复复位。PDI 故障还必须满足现有新 PDO、低电平后复位、连续健康通信等条件。

停止过程中，新的故障会取消旧的普通停止请求，避免随后某次同步中断把故障状态覆盖成普通禁用状态。

本次还在 `UpPwm()` 最终写入入口增加使能/AL/状态机/故障门控。普通禁止运行、撤电压、非 OP 或保护条件下，库算法即使请求非零 PWM，也会被改为四路零输出；Halt 和 Quick Stop Active 可保留受控减速/保持电流。**停用后可能失去保持力，竖直或重力负载必须有独立制动/支撑后才能测试。** 这是软件门控，不是 STO，也没有证明外部功率级在所有失效模式下都已断电。

## 4. 接口和参考文档中的差异

- 保留本机 VendorID、ProductCode=`0x15530111`、Revision=`3`，不复制成品身份。新增对象属于本机接口。
- 默认 RxPDO/TxPDO 仍各 12 字节，顺序不变；现有 GVL_CSP_NEW 不需要重新排列映射。
- 6085 的 C 描述修正为 UNSIGNED32，与 XML 一致。本版改为仅 SDO 配置，以免 PDO 绕过参数校验；若旧工程自行把 6085 放入 PDO，必须移除该映射后再启用。
- 605A 支持集合 0/1/2/5/6；605B、605C 支持 0/1；605D 支持 1/2；605E 支持 0/1/2。其他值被拒绝，尤其不虚报电流/电压制动。
- 60B0 按 CSP 位置偏移实现。参考手册列出了它，但提供的 XML 中没有该对象。
- 手册将 6082 写作“起跳速度”，提供的 XML 没有它；标准语义通常为 End velocity。本版不凭此实现未经确认的起跳速度。
- 手册有 bit5“上升沿”的文字，但其 002F→003F 示例实际翻转 bit4。本版遵循该可执行握手序列，不把 bit5 也当作必须跳变的触发源。
- 20F1 的量程/单位不能套用到本机功率级。在确认电流算法源码/库 API、采样比例和额定峰值/RMS 后，才能补足真实电流设置。

停止选项语义核对参考：[Kollmorgen 605A 说明](https://webhelp.kollmorgen.com/studio/Content/Kollmorgen%20Studio/Object%20Dictionary/Quick_stop_option_code.htm)、[Novanta 605A 说明](https://drives.novantamotion.com/summit/0x605a-quick-stop-option-code)。这些厂商资料用于交叉核对，不构成本机的合规认证。

## 5. 验证与实板门槛

离线工具：`tests/verify_drive_features.py` 执行实际 Keil ARM 镜像，覆盖 Halt、快速停止、撤使能、OP/PDI 故障、硬件故障完成、故障边沿、参数拒绝、单位换算、偏移、速度上限、对象注册与未实现能力不声明。`tests/verify_drive_esi.py` 检查 XML 语法、类型/访问/默认值、身份与默认 PDO；不声称做过 XSD/CTT。

回归还包括既有 `verify_pdi_faults.py`、`verify_pulse_position.py`、`verify_ethercat_sync.js` 和 NewProject PLC 检查。最终结果见文档末尾记录。

实板尚未验证。需要在无危险负载/有独立停机手段条件下核验：正反转 PP/PV、两种 Halt、Quick Stop 2/6、减速中撤使能、停网/PDI 故障、故障复位不自启动、最大 ISR 时间、额定电流/温升和长期同步稳定性。MCU 计数等于目标不代表机械位置准确。

之前 Realtek demo 网卡引发的帧时序/WcState 问题没有因本次功能补齐而被证明解决；现有通信诊断、PLC 锁存保护及不自动重启策略保持，不以放宽保护换取“不断转”。
